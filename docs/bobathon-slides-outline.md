# Ingram Micro Bobathon: Presentation Slide Deck Outline

This outline is structured for a 60–90 minute interactive Bobathon event featuring live demonstrations of IBM Bob.

---

## Slide 1: Title Slide
* **Title**: Accelerating Enterprise Agility with IBM Bob
* **Subtitle**: The Ingram Micro Bobathon: Live AI-Assisted Engineering & Workflow Transformation
* **Speakers**: Engineering Leadership & AI Champions

## Slide 2: The Modern Developer & Business Landscape
* The cognitive load of modern cloud distribution: complex catalog syncs, billing proration, legacy monolithic ERPs, multi-tier partner margins.
* How AI transforms everyday workflows from reactive manual labour to high-leverage engineering.

## Slide 3: Meet IBM Bob
* Modes: **Ask** (Knowledge/Docs), **Plan** (Architecture/Scoping), **Agent** (Surgical Code Generation & File Operations).
* Enterprise Guardrails: IBM Security Guidelines, compliance-first code generation, localhost safety, no secret leakage.
* Tooling Integration: OfficeCLI (Word, Excel, PowerPoint), Git diffs, linting, automated testing.

## Slides 11–13: Tier 3 Deep Dive & Live Demos (35 min)

## Slide 14: Best Practices & Prompt Engineering Tips
* Use **Plan Mode** for complex tasks with multiple dependencies.
* Keep context files concise and modular.
* Leverage structured formats (JSON, dataclasses, Gherkin) to guide output determinism.
* Iterate iteratively using subagents and targeted diffs.
