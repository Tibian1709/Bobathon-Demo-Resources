# Tic-Tac-Toe (Java Swing)

A simple **Tic-Tac-Toe game** built with Java Swing.  
Two players take turns (X and O) on the same computer. The app detects wins, draws, highlights the winning line, and includes a **Reset Game** button.

---

## Features
- 🎮 Classic 3×3 Tic-Tac-Toe grid  
- 👥 Two-player, pass-and-play  
- 🏆 Win detection with highlight effect  
- 🤝 Draw detection  
- 🔄 Reset button to restart anytime  
- 🎨 Customizable colors (board, players, winning line)

## Getting Started

### Requirements
- Java 17 or later  
- IntelliJ IDEA (Community or Ultimate) or any Java IDE

### Running the Game
1. Open IntelliJ IDEA.  
2. Go to **File → New Project → Java** and make sure an SDK (17+) is selected.  
3. Add a new Java class named `TicTacToe`.  
4. Copy the contents of `TicTacToe.java` into the new file.  
5. Press the green ▶ next to the `main` method to run.  

---

## Customization

You can easily change the look and feel of the game by editing a few lines in `TicTacToe.java`.
